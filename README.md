# MIOS — Aplicativo para acompanhamento médico de idosos com demência

O MIOS é um aplicativo desenvolvido com o objetivo de auxiliar no acompanhamento médico de idosos com demência, com foco no suporte ao cuidador.

O envelhecimento populacional tem contribuído para o aumento da incidência de doenças neurodegenerativas, especialmente as demências, que afetam significativamente as funções cognitivas e comportamentais dos indivíduos. Nesse contexto, torna-se essencial o acompanhamento contínuo desses pacientes.

O aplicativo busca facilitar o registro de sintomas, a organização do histórico e o compartilhamento de informações relevantes com profissionais de saúde e familiares.

## Objetivo

Desenvolver um aplicativo para acompanhamento médico de idosos com demência, oferecendo suporte aos cuidadores por meio do registro e da organização de informações sobre a rotina e as alterações apresentadas pelos idosos.

## Funcionalidades

- Cadastro e login de usuários;
- Cadastro de idosos;
- Registro diário de informações;
- Acompanhamento de sintomas e alterações comportamentais;
- Gravação e transcrição de áudio;
- Organização do histórico;
- Compartilhamento de relatórios.

## Tecnologias utilizadas

- React Native;
- Expo;
- TypeScript;
- SQLite;
- JavaScript.

## Como executar o projeto

Instale as dependências:

```bash
npm install
```

Inicie o aplicativo:

```bash
npx expo start
```
